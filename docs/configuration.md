# 解析配置

[← 返回 README](../README.md)

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| OCR 识别 | 自动 | 自动：只识别没有文字层或文字乱码的页。强制：重新识别所有含图像的页。关闭：不识别。 |
| OCR 清晰度 | 200 dpi | 150 dpi 更快，但表格中的短数字容易识别错误。300 dpi 更准，但更慢。 |
| 去页眉页脚 | 启用 | 删除识别出的页眉、页脚和页码。 |
| 分隔符 | `===CHUNK===` | 新版本使用新分隔符。如果只修改分隔符，系统保留当前结果中的手工修改。 |
| 最大 / 最小字数 | 1000 / 200 | 字数包含章节路径行。如果单行内容无法再拆分，系统提示超长。 |
| 块上下文 | 章节路径 | 3 种：章节路径（面包屑）、重复上级 `#` 标题、不添加。页码可以单独关闭。 |
| 表格格式 | Markdown | Markdown 表格或键值行。 |
| 表格每块最多行 | 0 | 0 表示只按字数拆分。 |

## 重新解析

点击「重新解析分块」打开「解析配置」抽屉。确认后，系统应用新设置并生成新版本。取消后，当前结果保持不变。

- 只修改分块参数：服务端复用已有的解析结果，只重新分块。
- 修改识别参数：服务端重新解析 PDF。

新版本独立保存。旧版本的内容和手工修改保持不变。
