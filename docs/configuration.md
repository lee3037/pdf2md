# 解析配置

[← 返回 README](../README.md)

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 解析方案 | PyMuPDF + RapidOCR | 默认方案在本机解析。OXR 把整份 PDF 发送到配置的 OXR 服务。 |
| OCR | 自动 | 仅适用于默认方案。自动识别没有文字层或文字乱码的页。「全部」重新识别所有含图像的页。「关闭」只提取文字层。 |
| 分辨率 | 200 dpi | 仅适用于默认方案。支持 150、200、300 dpi。小字号和表格数字需要重点核对。 |
| 去页眉页脚 | 启用 | 删除识别出的页眉、页脚和页码。 |
| 分隔符 | `===CHUNK===` | 新版本使用新分隔符。如果只修改分隔符，系统保留当前结果中的手工修改。 |
| 最少 / 最多字数 | 200 / 1000 | 字数包含章节路径行。无法拆分的表格行或完整公式可能超限，系统会提示。 |
| 块开头 | 路径 | 「路径」添加章节路径；「标题」重复上级 `#` 标题；「无」不添加章节信息。 |
| 来源页码 | 启用 | 在块开头标注来源页码。 |
| 表格格式 | Markdown | Markdown 表格或键值行。 |
| 每块行数 | 不限 | 「不限」对应值 0，表示只按字数拆分。 |

## OXR

在「解析配置」中把「解析方案」设为「OXR」。系统隐藏本地 OCR 模式和分辨率设置，保留「去页眉页脚」。切回默认方案后，系统恢复之前的本地设置。

OXR 默认使用官方免费 API，每份文件最多 10 MB、20 页。服务地址在服务器上配置，见[部署](deployment.md#oxr-服务)。选择 OXR 后，系统上传整份 PDF。OXR 失败时，系统显示错误，不自动改用其他方案。

系统保留所选方案。如果服务端不再提供这个方案，界面显示「暂不可用」。重新选择可用方案后，才能开始解析。

## 重新解析

点击「重新解析分块」打开「解析配置」抽屉。确认后，系统应用新设置并生成新版本。取消后，当前结果保持不变。

- 只修改分块参数：服务端复用已有的解析结果，只重新分块。
- 修改解析方案、去页眉页脚或当前方案的识别参数：服务端重新解析 PDF。

新版本独立保存。旧版本的内容和手工修改保持不变。
