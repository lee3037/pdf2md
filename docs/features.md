# 功能详解

[← 返回 README](../README.md)

## 解析

- **解析方案**：默认使用 PyMuPDF + RapidOCR。系统用 PyMuPDF 分析版面，按需调用 RapidOCR。OXR 作为可选方案，通过 HTTP 识别整份 PDF。
- **标题层级**：系统根据编号体例、出现顺序和字号推断标题级别。编号体例包括第X章、第X节、一、（一）、1.、1.1、1.1.1、（1）、附录、Chapter。如果 PDF 有书签目录，系统用书签目录校正标题级别。
- **正文与阅读顺序**：默认方案按双栏阅读顺序重排正文，按缩进和句末标点拆分段落。中文折行直接相连，英文断词的连字符被合并。OXR 保留服务返回的块顺序和段落边界。列表层级按编号样式推断。
- **页眉、页脚、页码**：系统识别并删除页眉页脚。识别方法有 3 种：版面模型、页面边缘的跨页重复文字、页码格式。页码格式包括 `- 3 -`、`第3页 共10页`、`3/10`、`Page 3 of 10`。
- **跨页续接**：两种方案都支持段落和表格的跨页合并。系统删除续表的重复表头和「续表」标记，并把首列为空的行接回上一行。默认方案还支持跨栏段落续接。
- **表格**：默认方案按真实框线取单元格，按字符坐标取文字。合并单元格的内容填入它覆盖的每一格。默认方案最多合并 3 行表头，输出「上级 / 下级」。扫描件表格中有墨迹但没有文字的单元格，系统以 300 dpi 重新识别。OXR 返回 HTML 表格，系统按表头标记合并多行表头；没有标记时，根据合并格结构推断。OXR 表格展开合并单元格后复用表格分块。表内上下标保留为 `^{内容}` 和 `_{内容}`。

## 分块

- **语义分块**：系统以章节为单位分块。章节内按段落、句子、列表项和表格行装箱。标题、以冒号结尾的引导语、表名与后续内容放在同一块。过短的块只与同一父章节内的块合并，不跨顶层章节。
- **长表格**：长表格按行拆块，每块重复表头和表名，并标注「续」。表格可以输出为「键值行」格式（`- 列名：值；…`），宽表用这种格式检索效果更好。
- **块上下文**：每块第一行写出章节路径和页码，例如 `> 章节：A > B > C ｜ 页码：3-4`。拆开的段落和表格按实际所在页标注页码。

输出示例：

```markdown
> 章节：信息安全管理制度 > 第二章 资产管理 > 2.1 资产清单 ｜ 页码：2-3

（续表）

| 序号 | 设备编号 | 类型 | 数量 | 存放位置 |
| --- | --- | --- | --- | --- |
| 25 | 设备-025 | 服务器 | 125 | 机房2号 |
...

===CHUNK===
```

## 工作区

- **文件管理**：左侧列出项目中的 PDF，并标记已转换的文件。首页列出最近打开的项目。
- **解析**：系统显示解析进度。目录外的 PDF 可以拖拽上传。
- **编辑**：支持 Markdown 编辑和渲染预览。「分块」视图显示每块的字数，并标记超长块和偏短块。点击页码会跳转到原 PDF 的对应页。
- **版本**：每次生成新版本，结果可以保存到目录或下载。

## 已知局限

- 默认方案可能无法完整识别扫描件中的无框线表格和复杂嵌套表格。对识别结果，重点核对数字和专有名词。
- 默认方案只保留图片中的成段文字。默认方案保留公式文字层，不转换为 LaTeX。OXR 保留识别出的 LaTeX，预览暂不排版公式。
- OXR 没有字体和行级坐标。系统按标题编号与 PDF 书签推断层级，无编号标题的层级可能需要人工调整。
- OXR 的图片不导出，系统提示对应页码。表内图片保留「图片未导出」占位文字。嵌套表格或一个内容块内的多个表格会返回错误。
- 公式整体保留。如果公式超过最大字数，系统提示超限，不截断 LaTeX。
- OXR 使用远程服务。免费服务可能拒绝过大文件，也可能因排队而超时。
- 语义分块基于章节结构和段落、句子边界，不调用大模型。
