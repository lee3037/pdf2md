# 使用指南

## 转换 PDF

前置条件：

- 服务已启动。启动方法见 [README](../README.md#快速开始)。
- 浏览器是 Chrome 或 Edge。写回目录必须用这两种浏览器。

步骤：

1. 在浏览器中打开 `http://<服务器>:8000/`。
2. 点击「选择目录」，选择本机的一个目录作为项目。
3. 在左上的 PDF 列表中点击一个 PDF。列表包含最多 4 层子目录。
4. 在抽屉中点击「开始解析分块」。
5. 在「解析配置」中选择解析方案并确认参数。
6. 点击「开始解析」。系统开始转换。
7. 在「分块」视图中校对内容。点击页码对照原文。
8. 点击「保存到目录」或按 `Ctrl/⌘ S`。

系统默认使用 PyMuPDF + RapidOCR。选择 OXR 后，系统把整份 PDF 发送到配置的 OXR 服务。方案与参数说明见[解析配置](configuration.md)。

> [!IMPORTANT]
> 写回目录依赖 File System Access API。只有 Chrome 或 Edge 通过 HTTPS 或 `localhost` 访问时，写回目录才可用。其他情况下，系统以只读方式打开目录，结果改为下载 `.md` 文件。

## 项目与版本

- 已转换的 PDF：点击后打开最新版本的 Markdown。
- 添加 PDF：点击 PDF 列表右上的「添加 PDF」，系统把所选文件复制到项目根目录。同名文件不会被覆盖。只读项目不能添加文件。
- 版本命名：第一次生成的文件名为 `文件名_v1.md`。再次生成时依次使用 `_v2`、`_v3`，旧版本保留。原有的无后缀 `.md` 文件按第 1 版计数，文件名保持不变。
- 版本号：系统按目录中和当前会话中的最大编号递增。
- 产物导航：左下列出已保存的版本和本次生成的版本。

> [!WARNING]
> 未保存的版本只存在于当前会话中。关闭页面前，保存或下载这些版本。

从目录重新打开的 `.md` 文件没有服务端任务和解析统计。系统按当前分隔符或本机保存的分隔符识别分块，并支持对照本地 PDF。如果重新解析这类文件，服务端创建新任务。

## 导入 RAG 知识库

Stratum 输出的 `.md` 文件用分隔符隔开每一块。任何支持「自定义分隔符分块」的知识库都可以直接导入。

1. 在目标知识库中导入 `.md` 文件。
2. 把分块方式设为按自定义分隔符分块。
3. 填入与 Stratum 相同的分隔符。默认分隔符是 `===CHUNK===`。
4. 把知识库的最大分块长度设为不小于 Stratum 的「最大字数」。

> [!IMPORTANT]
> 如果知识库的最大分块长度小于 Stratum 的「最大字数」，知识库会把块再次截断。

<details>
<summary>示例：FastGPT</summary>

1. 新建或打开知识库。
2. 选择文本数据集，通过本地文件导入 `.md` 文件。
3. 把处理方式设为「直接分块」。
4. 把分块模式设为「自定义分隔符」，填入 `===CHUNK===`。
5. 把「最大分块大小」设为不小于 Stratum 的「最大字数」。

</details>
